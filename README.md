



##### **1. Project Name**



Even or Odd Number Checker



##### **2. Description**



The Even or Odd Number Checker is a simple Python program that accepts an integer from the user and determines whether the number is **"even or odd"**. 

The program uses the **modulus (%) operator** to find the remainder when the number is divided by 2.



##### **3. Technology Used**



* Programming Language: Python
* Operator Used: % (Modulus)
* Conditional Statement: if-else
* Input Method: input()
* Output Method: print()



##### **4. Tools Required**



* Python 3.x
* Any Python IDE or code editor, such as:



* &#x20;  IDLE

##### **5. Features**



* Accepts a number from the user.
* Checks whether the number is even or odd.
* Uses a simple "if-else" condition.
* Correctly handles "positive and negative numbers".
* Easy to understand and execute.
* Suitable for beginners learning Python.



##### **6. How It Works**



The program divides the entered number by '2' using the modulus operator.



* If 'number % 2 == 0', the number is "Even".
* Otherwise, the number is "Odd".



For example:



text

8 % 2 = 0 → Even

7 % 2 = 1 → Odd



##### **7. Program Execution**



1\. Start the Python program.

2\. The program asks the user to enter a number.

3\. The user enters an integer.

4\. The `%` operator checks the remainder after division by 2.

5\. The `if-else` statement checks the result.

6\. The program displays "Even" or "Odd".

7\. The program ends.
